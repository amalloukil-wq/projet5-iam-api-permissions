ETAPE 5 - TEST DANS LE NAVIGATEUR (http://localhost:4200)
=====================================================================
(Si une ancienne session est affichee, cliquer d'abord sur "Deconnexion".)

 1. Bouton "GET /docs sans jeton"                    -> 401 (orange)
 2. "Se connecter" avec amartin / secret             -> groupes Admins, Staff
 3. GET /docs                                        -> 200
 4. POST /docs                                       -> 201
 5. DELETE /docs/2                                   -> 200 (manager)
 6. Deconnexion, puis bdupont / secret
    DELETE /docs/1                                   -> 403 (pas son document)
 7. Deconnexion, puis epetit / secret
    POST /docs                                       -> 403 "role insuffisant"
 8. Menu "introspection", refaire un appel           -> memes resultats

(Les delais de quelques secondes varient un peu d'un essai a l'autre ;
